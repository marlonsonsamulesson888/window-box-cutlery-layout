# 厂内默认排布规则（可配置）

全部可以在输入 JSON 的 `rules` 里覆盖。数值来自本厂 16/20 件开窗盒多轮定稿和刀模绘制标准；换客户、换内托结构时先确认。

| 键 | 默认 | 含义 |
|---|---|---|
| gap_mm | 6 | 相邻两支**最宽处**之间的净距 |
| pitch_round_mm | 0.5 | 中心距取整步长 |
| item_clearance_min_mm | 8 | 组外包络（最宽处）到窗左右边最少净距 |
| item_clearance_target_mm | 10 | 建议窗宽时用的净距 |
| side_paper_min_mm | 10 | 窗边到盒面左右压痕最少留纸（刀模标准：窗边距最近压痕 ≥10） |
| head_below_window_top_mm | [5, 15] | 头顶低于该列窗沿的建议范围；<0 = 头露出窗外，fail |
| handle_end_margin_mm | 10 | 柄尾要么在窗内且离窗底 ≥10，要么压在纸下 ≥10；夹在 ±10 之间看起来像被窗边切断 |
| decoration_from_fold_min_mm | 5 | 屋脊、花边等装饰离盒顶折线最少距离 |
| film_overlap_mm | 10 | 窗膜每边比窗口大 |
| film_to_fold_min_mm | 2 | 窗膜边离折线最少，避免压进折位 |
| inner_corner_radius_min_mm | 1.5 | 窗口内凹尖角最少倒圆（刀模可切、膜不易撕） |
| window_width_round_mm | 1 | 建议窗宽向上取整步长 |

## 其他约定
- 刀一般贴内底放（垫高 0），其余按头部对齐或固定高度放，垫高 = 内底 − 柄尾位置，交内托做垫块。
- 同一系列 16 件与 20 件共享的相邻关系（如刀–叉）可锁定同一中心距，保证两盒看起来是一套。
- 主餐勺头常见 38–46mm，是决定窗宽的最宽件；最宽件超出可行区间时先报“仅能做少件数版本”，再讨论改款。
- 所有数字是“距盒面左边/盒顶”的毫米数，和效果图像素换算时写清 px/mm。
